## 📄 Descripción

**Dev Coop** es una aplicación web de comercio electrónico moderna, rápida y responsiva. Este proyecto fue desarrollado como una propuesta tecnológica para la **Cámara de Comercio de Montería**, con el objetivo de demostrar una interfaz de usuario escalable y una gestión de estado eficiente.

El sistema consume datos dinámicos utilizando la **Platzi Fake Store API**, simulando un entorno real de productos, categorías y usuarios.

## ✨ Características Principales

* 🚀 **Diseño Responsivo & Dark Mode:** Interfaz minimalista adaptada a móviles y escritorio con estética oscura (Zinc/Black themes).
* 🛒 **Carrito de Compras Inteligente:** Gestión de estado global mediante React Context.
* 🔍 **Filtrado en Tiempo Real:** Búsqueda de productos por título y categorías sin recargas.
* 🔒 **Simulación de Autenticación:** Sistema de Login/Sign-up persistente.
* 💾 **Persistencia de Datos:** Uso de `LocalStorage` para mantener sesiones y órdenes de compra.
* ⚡ **Rendimiento Optimizado:** Construido sobre Vite para tiempos de carga instantáneos.

## 🛠️ Stack Tecnológico

| Tecnología | Propósito |
| :--- | :--- |
| **⚛️ React.js** | Biblioteca principal para la construcción de interfaces y componentes. |
| **🎨 Tailwind CSS** | Framework de utilidades para un diseño rápido, moderno y responsiva. |
| **⚡ Vite** | Entorno de desarrollo de próxima generación y empaquetador. |
| **🔗 React Router** | Manejo de rutas y navegación SPA (Single Page Application). |
| **🌐 Platzi API** | API REST para la obtención de productos ficticios. |

## 🚀 Instalación y Despliegue

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

1.  **Clonar el repositorio**
    ```bash
    git clone https://github.com/xnzperez/DevCoop-MiPymes.git
    ```

2.  **Entrar al directorio**
    ```bash
    cd DevCoop-MiPymes
    ```

3.  **Instalar dependencias**
    ```bash
    npm install
    ```

4.  **Ejecutar servidor de desarrollo**
    ```bash
    npm run dev
    ```
